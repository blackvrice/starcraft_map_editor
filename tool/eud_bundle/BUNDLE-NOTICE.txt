Modification: lib/library.zip's autoupdate.pyc is replaced with the readable
autoupdate.py source shipped in this application's repository. Its sole public
entry point issueAutoUpdate prints an informational message and returns.
There is no update check, download, update prompt, worker thread or exit hook.
All other upstream files and library entries retain their original contents.
The library ZIP container is repacked deterministically without compression.
This is an editor-managed derivative, not an unmodified official distribution.

Original license.txt, frozen_application_license.txt, share/licenses and all
library ZIP license/metadata entries are preserved. Consult these notices for
the licenses of euddraft, Python, cx_Freeze and the included dependencies.
Additional Python, eudplib, Pygments, OpenSSL, libffi, StormLib and Rust notices
are in editor-licenses. SOURCES.md records their provenance and review limits.
The application is not affiliated with the upstream authors.

User Python/plugins remain executable code. Disabling the built-in updater
does not sandbox arbitrary plugins or prevent their network/filesystem access.
An explicitly selected external tool retains its own update behavior.
