# ISOM 전환 연결표·수직 적층 재계산

2026-10-01. 평지 채우기에 이어 **기존 ISOM의 전환 형태와 수직 적층에서
TILE/MTXM을 재계산**하는 기능을 구현했다. 새 지형 경계·높이·경사로를 그리는
브러시와 인접 다이아몬드의 자동 경계 조정은 다음 단계다.

## 사용

File → 등각 지형 채우기에서 **기존 ISOM 재계산**을 선택한다.
변경 타일 수를 확인하고 **재계산한 타일 적용**을 누른다. 조회/미리보기는 문서를
바꾸지 않는다. 적용은 공통 Undo 한 건이며 기존 Save As로 저장한다.
ISOM의 바이트·에디터 플래그는 보존하고 TILE/MTXM만 함께 교체한다.
변경이 없으면 적용 버튼은 비활성화된다. 평지 채우기는 기존 기능으로 유지한다.

유일한 정상 DIM/ERA/ISOM/TILE/MTXM, 짝수 폭·최대 256×256, TILE==MTXM이 필요하다.
두다드·보호/손상/중복 지형·알 수 없는 ISOM은 거부한다. 재계산 모드는 기존 모든
타일 쌍의 종류·좌우 관계·member도 카탈로그에 있어야 한다. 미지원 특수 타일을
추측하여 일반 지형으로 교체하지 않는다. 전체 평지 교체의 명시적 채움과 구분한다.

## 연결표

`TransitionIsomCatalogBuilder`는 기존 snapshot v2/helper 0.11.0을 소비한다.
새 네이티브 작업이나 자산 배포는 없다. 모든 표를 같은 snapshot에서 만들고
revision을 `transition-isom-v1:<snapshot revision>`으로 결합한다.

- 평지 표와 타일셋별 전환 종류의 ISOM 시작 번호, 종류당 14개 형태를 조립한다.
- TL/TR/BR/BL 사분면마다 2개 변을 투영한다. 0x0..0xE의 짝수 edge flag가 각각
  다른 연결을 가리키며 하나의 shape 번호를 모든 방향에 동일한 값으로 쓰지 않는다.
- hard-link 패턴과 적층 최상단 조건을 대조한다. CV5의 증가하는 group 순서에서
  후행 적층 행이 해당 사분면의 기준이 된다. 입력 배열 순서에는 의존하지 않는다.
- 전용 오목 사분면이 없는 east/west는 검증된 대각 경계의 변으로 조립한다.
  평지 사분면은 인접 연결로 채운다. 필수 사분면 누락은 전체 조회 실패다.
- CV5 1024 미만의 짝수 좌측/다음 우측 그룹만 사용한다. 종류·4개 연결·4개 적층
  단어가 좌우에서 같아야 하며 renderable/nonzero member 교집합을 사용한다.
  기존 Platform Space의 canonical member 0 예외는 평지 공급자만 처리한다.
- **48은 soft-link**다. 49 이상 hard-link에서만 terrain type을 키에 포함한다.
  한 ISOM 사각형에 서로 다른 hard-link 종류가 있으면 거부한다.

숫자 형태 정의와 사분면 조립 규칙은 고정
[Chkdraft sc.h](https://github.com/TheNitesWhoSay/Chkdraft/blob/32d27861b16dda0b0f3d95e34bad894ea4efb2c3/src/mapping_core/sc.h)와
[sc.cpp](https://github.com/TheNitesWhoSay/Chkdraft/blob/32d27861b16dda0b0f3d95e34bad894ea4efb2c3/src/mapping_core/sc.cpp)를
대조·적용했다. [MIT 고지](licenses/Chkdraft.txt)를 유지하고 Windows 번들의
`licenses/Chkdraft.txt`에 설치한다. 게임 원시 자료나 추출 이미지는 저장소에 넣지 않는다.

## 수직 적층 변환

순수 domain `IsomTerrainConverter`는 열 전체에 대해 동적 계획법으로 타일 쌍과
member 경로를 고른다. 앞 행의 bottom과 다음 행의 top이 같아야 하며 0과 nonzero를
연결하지 않는다. 연결된 적층 행에는 공통 member가 필요하다. 비용은 변경할 타일 수로,
기존 유효한 쌍/변형을 최대한 유지한다. 같은 입력·seed·카탈로그는 같은 결과를 만든다.

위·아래 맵 끝에서는 적층을 잘라낼 수 있지만 내부 불일치는 허용하지 않는다.
수평 적층은 미지원이다. 선택 경로가 없으면 전체 실패하고 입력을 그대로 보존한다.
padding의 미지원 ISOM도 거부한다. 모든 조회·계산은 메모리에서 수행하고 UI는
application 컨트롤러 뒤에서 자료를 사용한다. 기존 취소·설정/맵 identity·transaction·
진행 작업 검사와 리소스/객체 보존을 유지한다.

이는 ISOM → 타일 변환이다. 인접 다이아몬드의 의미 일치, 경계 자동 연결,
경사로 생성·보행 가능성 또는 외부 에디터와 동일한 난수는 보증하지 않는다.
미지원 맵의 자동 복구 기능이 아니다.

## 검증

독립 합성 NW 사분면 예상값, 14개 형태·입력 순서, 사분면/우측 그룹 누락,
soft-link 48, 막다른 적층·공통 member 부재·입력 보존을 검사했다.
한글/영문 UI에서 ISOM 플래그 보존·조회 무변경·적용·Undo/Redo를 확인했다.

각 적층 쌍을 포함하는 CV5 top/bottom 경로를 독립 탐색하고, 해당 연결 키를 가진
합성 ISOM에서 변환·재적용 무변경·CHK 왕복과 생성 타일의 실제 렌더 참조를 확인했다.
이 테스트는 편집 가능한 전체 다이아몬드 경계를 생성하는 테스트가 아니다.
합성 적층/비적층 MPQ와 실제 평지 Save As/재열기는 입력 fingerprint와 ISOM을 보존했다.

전체 Flutter 895개 통과/40개 환경 skip, 실제 설치/MPQ 추가 스모크 5개 통과,
analyze 무이슈, Windows debug 빌드·4초 앱 시작 및 동봉 MIT 고지 해시 일치 확인.
변경 Dart format은 통과했다. 전체 비쓰기 format 검사는 기존 무관한 infrastructure
테스트 3개 차이로 미통과다. SDK Flutter 3.47.5/Dart 3.13.4는 기준 3.44.8/3.12와
다르며 기준 SDK CI·실제 게임·외부 에디터 인수는 수행하지 않았다.
기존 CascLib CMake 최소 버전 경고는 남는다. 네이티브 소스는 변경하지 않았다.

다음 구현은 다이아몬드 인접성·지형 종류 사이 전환 경로와 경계 자동 계산,
선택 영역·높이 전환·경사로 브러시·시각 타일 미리보기다. ISOM/두다드 resize도 남는다.
