# 기본 맵 에디터 기능 대조표

- 점검일: 2026-09-07
- 코드 기준: `59414bb` 및 현재 작업 트리의 관련 편집 코드
- 목적: 기존 StarEdit/ScmDraft 계열의 기본 UMS 제작 기능이 요구사항과 실행 가능한 개발 항목에 연결되어 있는지 확인한다.

## 1. 점검 결론과 판정 기준

기존 계획은 기본 맵 에디터 전체를 포괄하지 않았다. M6의 객체 속성 편집은
배치된 객체의 일부 필드를 수정하는 기능이며, 맵 전체 Unit Settings를 포함하지
않는다. 플레이어·세력 설정은 요구사항/포맷 문서에만 있었고, 유닛 종류별 설정,
업그레이드와 테크 설정은 구체적인 작업 항목이 없었다.

아래의 기존 상태는 이번 문서 보완 전 상태다. 구현 판정은 문서와 코드의 정적
대조이며 이번 점검에서 앱 UI나 실제 게임의 기능 완료를 재검증했다는 뜻은 아니다.
raw 섹션 보존, typed view 존재, 사용자 편집 완료는 서로 다른 상태로 취급한다.
M0~M6.1의 완료 표시는 당시 범위의 완료이며 기본 에디터 전체의 완료가 아니다.

## 3. 유닛 설정의 구분

예를 들어 배치된 마린 하나의 체력을 50%로 바꾸는 것은 기존 Inspector 범위다.
맵에서 마린의 최대 체력을 100으로 바꾸는 것은 새 Unit Settings 범위다.
M6.2의 factory도 배치 레코드 생성에 관한 것으로 Unit Settings를 대신하지 않는다.

구현 근거:

- `lib/application/editing/object_properties.dart`의 `UnitObjectPropertyUpdate`에는
  개별 객체의 수치 입력만 있고 맵 전체 설정 입력은 없다.
- `lib/domain/chk/typed/chk_object_editor.dart`는 그 개별 필드만 바꾸며 상태와
  valid flags를 보존한다. 설정 화면에서는 값과 적용 여부의 의미를 함께 검증해야 한다.
- `lib/domain/chk/chk_section_names.dart`와 현재 domain/application에는 유닛·
  업그레이드·테크·플레이어 설정의 typed 편집 경로가 없다.
- `lib/application/commands/editor_command_dispatcher.dart`의 파일 명령에는
  Open/Save As가 있고 New Map은 없다.

CHK 기반 설정과 EUD 확장을 구분한다. 사용자 요청으로 사거리·실드 활성·피해 유형
등의 설정을 M6.3.1에 추가했으며, 상세 범위는 [EUD 연동](EUD_INTEGRATION.md)의
14절을 따른다. 임의 그래픽/IScript 변경이나 EUD Editor 전체 호환을 뜻하지 않는다.

## 4. 범위와 완료 조건

이 표는 UMS 제작의 기본 기능 기준선이다. ScmDraft의 모든 버전·플러그인·확장
기능과 동등하다는 보장은 아니다. 새 기본 기능을 확인하면 이 표와 개발 계획의
체크박스를 함께 갱신한다. 각 행의 상세 지원 필드와 버전 규칙은 구현 전에
고정된 소스 및 자체 제작 픽스처로 확정한다.

고급 대칭/사용자 브러시, 기존 맵 타일셋 변환, 확장 지형, 다중 문서 간 붙여넣기,
텍스트 트리거 언어 완전 호환, 모드/DAT 편집, 보호 맵 해제는 기본 완료 기준과
분리한다. 특히 일반 등각 지형과 안개 편집은 고급 브러시라는 이유로 누락하지 않는다.

기존 MVP는 안전한 열기·저장·EUD 빌드의 수직 검증이며 기본 에디터 완성 기준이
아니다. 기본 에디터 완료에는 이 표의 기본 항목, M6.2~M7과 M8의 검증을 요구한다.
새 맵 생성 → 플레이어/세력/유닛/업그레이드/테크 설정 → 배치·지형·안개 편집 →
트리거/브리핑/사운드 구성 → Save As → 재열기 → 실제 SC:R 실행을 검사한다.

모든 새 편집은 Undo/Redo, 취소 시 무변경, 다른 섹션/예약 비트/원시 문자열 보존,
누락·중복·손상 입력 거부 또는 명시적 제한, 저장 왕복을 검증한다. 새 맵의
기본값 생성과 기존 맵의 누락 섹션을 추측해 복구하는 행위는 구분한다.

## 6. 문서 정리 검증

- 문서 내부 파일 링크, 요구사항 ID 중복과 `git diff --check` 검사 통과.
- 로컬 Flutter 3.47.2 / Dart 3.13.2에서 `flutter analyze --no-pub` 통과.
- 같은 환경의 `flutter test --no-pub --concurrency=1`: 378개 통과, 환경 의존 9개 skip.
- 저장소 기준 Flutter 3.44.8에서의 재검증과 실제 Windows 앱/게임 실행은 이번
  문서 점검에 포함하지 않았다. 기존 코드의 자동 테스트 통과가 새 계획 항목의
  구현 완료를 뜻하지 않는다.
