# 세력 설정

File → Force Settings에서 플레이어 1~8의 세력 배정과 세력 1~4의 이름,
시작 위치 무작위화, 동맹, 공동 승리, 시야 공유를 편집한다. 플레이어와 세력을
오가며 입력한 변경은 Apply로 한 명령에 적용한다. Cancel은 미적용 입력을
폐기하며 객체·맵 정보·플레이어 설정과 공유하는 Undo/Redo를 사용한다.
저장은 Save As이며 오래된 문서 스냅샷에는 적용하지 않는다.

## 바이트 보존과 지원 범위

- 단일 알려진 VER(59/63/205/206)와 정확히 20바이트인 단일 FORC가 필요하다.
  짧은 FORC를 게임이 기본값으로 읽을 수 있어도 이번 편집기는 확장하거나
  정규화하지 않는다. 누락·중복·다른 크기는 사유를 표시하고 편집을 차단한다.
- 오프셋 0~7은 플레이어별 세력 ID, 8~15는 세력 이름의 little-endian u16
  문자열 ID, 16~19는 세력별 옵션이다. 새 세력 배정은 0~3만 허용한다.
  비표준 기존 ID는 숫자로 표시하며 다른 플레이어 편집 시 보존한다.
- 옵션은 bit 0 시작 위치 무작위화, bit 1 동맹, bit 2 공동 승리, bit 3 시야
  공유를 편집한다. 상위 네 비트와 미편집 필드는 그대로 보존한다.
  배치된 시작 위치 UNIT을 이동하거나 생성하지 않는다.
- 이름은 안전한 STR 또는 STRx 하나와 유효한 UTF-8 참조가 필요하다. 이름별
  참조·인코딩 오류는 그 이름만 차단하며 배정과 옵션을 막지 않는다. 문자열 표
  자체가 없거나 모호하면 모든 이름 편집을 차단한다.
- 이름이 달라지면 새 문자열을 추가하고 그 세력의 참조만 바꾼다. 다른 세력,
  SPRP, 로케이션 등의 공유 참조와 원래 문자열·미참조 tail을 보존한다.
  빈 이름은 0 참조다. NUL과 새 ID가 65535를 넘는 변경은 전체 적용을 거부한다.

## 검증

도메인 테스트는 STR/STRx의 공유 문자열·원시 tail·예약 비트 보존, 선택 바이트,
무변경, 이름 삭제, 구조·범위·인코딩 오류와 u16 상한을 검증한다.
화면 테스트는 취소, 세력 사이 입력 유지, 배정·옵션·이름 일괄 적용과 Undo/Redo를
확인한다. 합성 CHK와 가짜 아카이브 gateway를 이용한 Save As/재열기 테스트는
원본 바이트 보존과 출력 설정을 확인한다. 실제 SC:R 로비·게임의 동맹·시야·승리
동작과 레거시 인코딩은 별도 검증이 필요하다.
