## 기존 결정 유지

- 실제 initialMap/live 전력·크립 collector는 사용자의 **에디터 우선, 실제 수집
  미지원 표시** 결정을 유지한다. 에디터 기능 완료를 실제 collector 완료로 세지 않는다.
- 실제 앱 조작은 **자동 테스트와 빌드만 진행** 지시를 유지한다. 게임/외부
  에디터/두 클라이언트/깨끗한 PC 인수는 자동 테스트 통과와 별도다.
- 기존 자동 저장, ISOM 지형, 기본 설정·일반 트리거, 같은 맵 혼합 복사,
  여러 맵 탭 편집은 이미 구현되어 있으며 누락 기능으로 재계산하지 않는다.
- 알 수 없는 CHK/예약 바이트·원본 파일·원시 문자열과 사용자 작업을 보존한다.
  구현/자동 검증/수동 앱/게임·외부/배포를 각각 판정한다.

실행 기록과 각 기능의 남은 검증은 위 연결 문서와 개발 계획에 남긴다.
전체 행의 코드·인수 조건이 충족되기 전에는 '남은 기능 전체 완료'로 보고하지 않는다.
