# 설정 검색과 범위 복사

Unit Settings(유닛·무기), Unit Availability, Upgrade Settings, Tech Settings에
공통 검색과 명시적 ID 범위 복사를 제공한다. 캔버스의 배치 객체 선택과 별개다.

## 검색

ID 또는 표시 문자열로 필터링하며 #12는 ID 12만 찾는다. 유닛 설정에서는
안전하게 읽힌 맵 사용자 이름과 이름 초안도 검색한다. 로컬 게임 이름이 연결되지
않은 목록에는 숫자 ID를 표시한다. 검색 결과가 없어도 현재 편집 선택과 초안을
유지하며 다른 항목을 자동 선택하지 않는다. 검색은 쓰기 대상을 정하지 않는다.

## 범위 복사

1. 원본 ID와 필요한 플레이어/맵 범위를 선택하고 복사할 필드만 수정한다.
2. Copy edited fields to IDs를 펼쳐 출발 항목과 범위 안내를 확인한다.
3. Target IDs에 0, 2-5처럼 ID 또는 오름차순 범위를 입력한다. 중복은 제거한다.
4. Prepare draft copies로 초안을 준비한다. 범위 오류나 수치 파싱 오류는
   초안을 부분 변경하지 않는다. 수정 필드가 없으면 아무것도 복사하지 않는다.
5. 대상 항목을 확인한 뒤 Apply한다. Cancel은 모든 미적용 초안을 버린다.

복사는 원본 ID의 **수정된 필드만** 대상으로 삼는다. 대상 ID의 같은 필드 초안은
덮어쓰고 다른 필드·다른 플레이어 초안은 보존한다. 입력한 범위 전체는 원본 버전의
ID 개수 안에 있어야 한다. 검색 결과 전체를 자동 대상으로 삼는 기능은 없다.

| 목록 | 복사 범위 |
| --- | --- |
| 유닛 설정 | 선택 유닛의 수정 수치·이름·기본값 플래그 |
| 무기 설정 | 선택 무기의 수정 기본/추가 피해량 |
| 생산 허용 | 선택 유닛의 수정 맵 기본값과 현재 플레이어 값/상속 |
| 업그레이드·테크 | 선택 ID의 수정 맵 비용과 현재 플레이어(또는 맵 기본) 설정 |

플레이어 선택 중 이전에 수정한 맵 기본 레벨/허용/연구 완료는 복사 대상에
포함하지 않는다. 비용은 맵 전체 설정이므로 함께 복사한다.
기본값/상속 플래그도 수정된 경우에만 복사한다. 대상이 기본값을 사용하면
복사한 사용자 수치가 저장되어도 비활성일 수 있다.
유닛 범위는 무기 피해량에 적용되지 않는다. 무기 범위는 별도로 지정하며
대상 무기를 공유하는 모든 유닛에 영향이 갈 수 있다.

## 검증·적용

준비 단계는 문서를 변경하지 않는다. Apply에서 기존 도메인 검증을 거쳐 전체
초안을 하나의 Undo/Redo 명령으로 적용한다. 업그레이드 시작/최대 관계 등
대상별 검증 실패 시 전체 적용을 거부하고 초안을 유지한다.
Save As와 미편집 바이트 보존 계약은 기존 설정 편집기와 동일하다.

범위 파서의 경계·중복·오류, 검색의 선택 불변, 다른 플레이어 초안 제외,
대상 레벨 오류의 원자적 거부를 검증한다. 다섯 선택 영역의 위젯 테스트는
원본/복사 대상의 섹션 바이트와 취소·Undo/Redo를 확인한다.

## 통합 탭과 플레이어 범위

[Map Settings 통합 탭](MAP_SETTINGS_UI.md)에서 탭별 초안과 충돌·닫기 보호를 제공한다.
Players/Forces 공통 선택과 1번부터 시작하는 플레이어·세력 범위도 지원한다.
실제 SC:R 적용 검증은 별도 항목으로 남아 있다.
