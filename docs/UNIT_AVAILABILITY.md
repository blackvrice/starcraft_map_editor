# 유닛 생산 허용

M6.3의 File → Unit Availability…에서 유닛 ID 0~227의 맵 공통 기본값과
플레이어 1~8의 생산 허용/금지, 기본값 상속을 편집한다. 플레이어 9~12의
저장 값은 읽기 전용으로 표시한다. 이 화면은 배치 객체 속성과 별개다.

## 편집 동작

- 맵 공통 기본값은 해당 유닛에서 기본값을 상속하는 모든 플레이어에 영향을 준다.
- 기본값 상속을 켜면 플레이어 덮어쓰기 입력을 비활성화하되 저장된 값은 지우지 않는다.
- 유닛/플레이어 선택을 바꿔도 초안을 유지한다. Apply는 모든 초안을 하나의
  Undo/Redo 명령으로 적용한다. Cancel은 미적용 초안을 버린다.
- 현재 선택의 최종 허용 상태를 초안 기준으로 표시한다. 비표준 플래그는
  숫자로 보존하며 결과가 불명확하면 unknown으로 표시한다.
- Apply는 메모리 문서를 변경한다. Save As는 기존 검증·임시 출력·재검증
  저장 경로를 사용한다. 열린 문서가 변경된 뒤 오래된 초안을 적용하면 거부한다.
- 생산 허용은 게임의 선행 조건을 해제하거나 배치된 유닛을 생성하는 기능이 아니다.

## CHK 계약

단일 알려진 VER(59/63/205/206)와 정확히 5700바이트인 단일 PUNI가 필요하다.
누락·중복·크기 불일치는 오류로 표시하고 섹션을 추측하여 생성/복구하지 않는다.

| 시작 오프셋 | 길이 | 값 |
| --- | --- | --- |
| 0 | 2736 | 플레이어 12 × 유닛 228의 개별 허용 플래그 |
| 2736 | 228 | 유닛별 맵 공통 기본 허용 플래그 |
| 2964 | 2736 | 플레이어 12 × 유닛 228의 기본값 상속 플래그 |

모두 u8, 플레이어 우선 배열이다. 허용 플래그는 0=금지, 1=허용이며
상속 플래그는 0=개별 값, 1=맵 기본값이다.
[SEN Scenario.chk의 PUNI 명세](https://wiki.staredit.net/wiki/Scenario.chk)를 따른다.
변경 요청이 있는 바이트만 교체하며 비표준 미편집 값, 예약 플레이어, 다른 섹션,
문자열 원시 바이트를 보존한다. 새 플래그는 0/1만 받는다.

## 검증과 제한

합성 CHK golden bytes로 마지막 편집 가능 플레이어/유닛의 오프셋, 예약 영역,
비표준 값 보존, 잘못된 입력의 원자적 거부, 상속 전환을 검증한다.
위젯 테스트로 취소·선택 간 초안·상속·읽기 전용·Undo/Redo를 확인한다.
가짜 아카이브 게이트웨이를 사용하는 통합 테스트로 Save As/재열기 후 정확한
PUNI 바이트와 오래된 문서의 적용 거부를 확인한다.

실제 SC:R 게임의 생산 동작은 아직 검증하지 않았다.
