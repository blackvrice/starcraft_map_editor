# 테크 설정

File → Tech Settings…에서 테크별 미네랄·가스·연구 시간·사용 에너지와
맵/플레이어별 허용·연구 완료·기본값 상속을 편집한다.

## 편집 규칙

- 알려진 단일 VER가 59/63이면 TECS/PTEC(24개), 205/206이면 TECx/PTEx(44개)를
  사용한다. 검증되지 않은 이름 대신 Tech #ID를 표시한다.
- 비용과 플레이어 상태 그룹은 독립 검증한다. 누락·중복·크기 오류가 있는
  그룹만 비활성화한다. 섹션을 추측해 생성하거나 반대 버전 섹션을 동기화하지 않는다.
- 비용·시간·에너지는 0~65535 정수다. 시간은 1/60초 단위다.
  에너지는 기술 사용 비용이며 배치 유닛의 현재 에너지나 최대 에너지와 별개다.
- 비용의 게임 기본값 플래그는 저장된 사용자 수치를 지우지 않는다.
  게임 기본 수치를 로컬 DAT에서 읽어 표시하는 기능은 아직 연결되지 않았다.
- 맵 기본 허용/연구 완료와 플레이어 1~8의 개별 값·상속을 지원한다.
  플레이어 9~12의 값은 읽기 전용으로 보존한다.
- 허용 여부와 연구 완료 여부는 독립 플래그다. 하나를 바꿔도 다른 하나를
  자동으로 변경하지 않는다. 게임의 선행 조건을 해제하는 기능은 아니다.
- 기본값 상속은 플레이어의 저장 값을 보존한다. 화면은 선택된 플레이어의
  초안을 반영한 최종 허용·연구 완료 상태를 보여준다.
- 새 플래그는 0/1만 받는다. 기존 비표준 값은 숫자로 유지하고, 결과가 불명확한
  항목은 unknown으로 표시한다. 미편집 값은 정규화하지 않는다.

선택을 바꿔도 초안을 유지한다. Apply는 모든 변경을 한 번에 검증하고 공유
Undo/Redo 명령으로 적용한다. Cancel은 미적용 초안을 버린다. 오류 후 초안은
유지하며 오래된 문서 스냅샷에 적용하는 요청은 거부한다.
Save As는 기존 검증·임시 출력·재검증 저장 경로를 사용한다.

## 저장 구조

[SEN CHK 명세](https://wiki.staredit.net/wiki/Scenario.chk)의 TECS/TECx와 PTEC/PTEx를 따른다.

| 비용 배열 | TECS 오프셋 | TECx 오프셋 |
| --- | --- | --- |
| 기본값 u8[N] | 0 | 0 |
| 미네랄 u16[N] | 24 | 44 |
| 가스 u16[N] | 72 | 132 |
| 연구 시간 u16[N] | 120 | 220 |
| 에너지 u16[N] | 168 | 308 |
| 전체 크기 | 216 | 396 |

N은 24/44이며 u16은 little endian이다. UPGx와 달리 중간 예약 바이트가 없다.
PTEC/PTEx는 플레이어 허용[12N], 플레이어 연구 완료[12N], 맵 허용[N],
맵 연구 완료[N], 플레이어 상속[12N]의 u8 배열이다.
시작 오프셋은 0, 12N, 24N, 25N, 26N, 전체 크기는 38N(912/1672)이다.

변경된 필드만 패치하며 미편집 값·예약 플레이어·반대 버전 섹션·알 수 없는
섹션·원시 문자열 바이트는 보존한다.

## 검증과 제한

합성 원본/확장 golden bytes로 모든 비용 배열의 마지막 항목과 플레이어 8의
마지막 테크 플래그를 확인한다. 잘못된 ID·값·버전·섹션 구조의 거부,
비용/상태 그룹 독립 처리, 기본값 보존과 허용/연구 완료의 독립성을 검증한다.
위젯 테스트는 선택 간 초안, 범위 오류 후 수정, 취소·기본값·상속·Undo/Redo,
비표준 플래그와 예약 플레이어 읽기 전용을 확인한다.
가짜 아카이브 통합 테스트는 Save As/재열기의 TECx/PTEx 전체 바이트와
오래된 문서의 적용 거부를 확인한다.

실제 SC:R 게임의 연구·사용 동작과 개별 테크의 유효 수치 상한은 미검증이다.
