# 맵 크기 변경

2026-09-29: File → Resize Map…에서 raw 타일 맵의 크기 변경 미리보기,
명시적 적용과 문서 공통 Undo/Redo를 지원한다. ISOM이 있거나 DD2 두다드가
있는 맵의 변환은 아직 지원하지 않으며 이유를 표시하고 적용을 차단한다.

## 사용 방법

1. 맵을 열고 **File → Resize Map…**을 선택한다.
2. 새 가로·세로를 32~256, 32 단위로 선택한다. Anchor는 기존 내용을 붙일
   9개 기준점이다. 중앙 정렬에서 홀수 차이는 음수 방향으로 내림한다.
3. 확장 영역에 사용할 기존 맵 타일의 X/Y 좌표를 지정한다(0부터 시작).
   미리보기에 실제 raw 타일 값이 표시된다. 새로운 종류의 타일은 생성하지 않는다.
4. 지형/안개에서 잘릴 셀·추가 셀, 이동할 유닛/스프라이트, 맵 밖으로 나갈 객체와
   잘릴 로케이션 수를 확인한다. 적용 전에는 문서와 Undo 기록을 변경하지 않는다.
5. 축소가 있으면 확인 체크 후 **Apply resize**를 누른다. Cancel은 변경하지 않는다.
   이후 Undo 한 번으로 전체 변경을 취소할 수 있다. 디스크 저장은 기존 Save As다.

## 지원 계약

- `DIM `, `MTXM`, 있으면 `TILE`·`MASK`, `UNIT`·`THG2`·`MRGN`을 한 번에 교체한다.
  누락된 선택 섹션은 합성하지 않고 같은 섹션의 중복이나 잘린 격자/레코드는 거부한다.
- 기존 MTXM/TILE/MASK 겹침 영역은 각각 원래 바이트를 복사한다. 새 MTXM/TILE
  셀은 선택한 MTXM raw 값으로 채우고, 새 MASK 셀은 모든 플레이어 숨김 `0xff`다.
- 유닛/스프라이트 좌표만 타일 이동량 × 32픽셀만큼 이동한다. 레코드 순서,
  class ID·연결 ID·예약 바이트는 유지한다. 객체가 새 경계를 벗어나면 적용을
  막는다. 객체를 자동 삭제하거나 관계를 추측해 수정하지 않는다.
- 로케이션은 ID·이름·고도 플래그를 유지하고 각 좌표를 새 경계로 제한한다.
  역방향 좌표는 정렬하지 않는다. 완전히 잘리는 영역은 경계의 면적 0 영역이 된다.
  빈 레코드는 그대로 두고, ID 64가 원래 맵 전체 영역일 때만 새 전체 영역으로 갱신한다.
- 알 수 없는 섹션, TRIG/MBRF, 원시 문자열·예약 값과 미저장 사운드는 유지한다.
  사용자 코드·EUD 규칙에 직접 적은 픽셀 좌표는 변환하지 않으므로 별도 검토해야 한다.
- 크기 변경 후 타일 선택/카메라 상태를 초기화한다. 변경 사이에 문서 교체·편집,
  저장/빌드 또는 브러시 작업이 발생하면 오래된 미리보기 적용을 거부한다.

## 계층과 안전

`MapResizeEditor`는 순수 도메인 변환과 불변 미리보기를 만든다.
`MapResizeController`는 캡처한 세션 identity, 진행 중 작업과 편집 제한을 확인하고
새 metadata/terrain/object/reference 진단을 검증한 뒤 한 번에 세션을 채택한다.
공통 history에 전후 세션을 기록하며 디스크 I/O는 하지 않는다.
UI는 컨트롤러를 통해서만 적용한다. 이후 Save As는 기존 임시 출력·재검증·승격을 따른다.

## 검증과 남은 범위

자동 테스트는 9개 anchor, 비정사각 확장, 중앙 축소, 지형/안개 겹침 바이트,
객체 이동·경계 거부, 로케이션 clipping/ID 보존, 중복·손상·ISOM/DD2 거부,
미리보기 취소, 오래된 세션·진행 중 브러시 거부와 Undo/Redo를 검사한다.
실제 MPQ 테스트는 저장된 입력의 크기를 변경하고 Save As·재열기에서 CHK 전체
일치와 원본 fingerprint 보존을 확인한다.

2026-09-29 검증: 전체 Flutter 테스트 791개 통과/29개 환경 선택 skip.
이후 추가한 축소 확인 UI 테스트를 포함해 관련 테스트 8개 모두 통과했고,
실제 MPQ 왕복 1개도 통과했다. analyze 무이슈, Windows debug 빌드 및
4초 시작 확인 통과. 변경 Dart 9개 format 통과; 전체 format은 기존 무관한
infrastructure 테스트 4개의 차이로 미통과다. Flutter 3.47.2/Dart 3.13.2에서
검증했으며 기준 3.44.8/3.12 재검증은 별도다. 기존 CascLib CMake 경고는 남아 있다.
실제 SC:R 및 외부 에디터 인수는 이번에 수행하지 않았다.
ISOM/두다드 변환은 등각 지형·복합 배치 소유권 검증과 함께 후속 개발한다.
유닛 footprint·지형 보행 가능성, 사용자 트리거/EUD 좌표의 의미는 자동 보장하지 않는다.
