# 맵 크기 변경

2026-10-01 확대: File → Resize Map…에서 raw·ISOM·검증된 DD2 두다드 맵의
크기 변경 미리보기, 명시적 적용과 문서 공통 Undo/Redo를 지원한다.
등각/두다드 맵은 Settings의 로컬 SC:R 자료를 자동 로드한다. 미확인 자료,
보호/손상 맵이나 잘리는 객체·footprint는 이유를 표시하고 적용을 차단한다.

## 사용 방법

1. 맵을 열고 **File → Resize Map…**을 선택한다.
2. 새 가로·세로를 32~256, 32 단위로 선택한다. Anchor는 기존 내용을 붙일
   9개 기준점이다. 중앙 정렬에서 홀수 차이는 음수 방향으로 내림한다.
3. 확장 영역에 사용할 기존 맵 타일의 X/Y 좌표를 지정한다(0부터 시작).
   raw 맵은 그 값을 복사한다. ISOM 확장은 표본 다이아몬드가 평지여야 하며
   검증된 해당 종류의 타일 쌍과 경계를 생성한다. 축소만 할 때는 채움 표본을 사용하지 않는다.
4. 지형/안개에서 잘릴 셀·추가 셀, 이동할 유닛/스프라이트, 맵 밖으로 나갈 객체와
   잘릴 로케이션 수와 이동/맵 밖 두다드·재계산 셀 수를 확인한다.
   재계산 셀 수는 임시 복사한 TILE과 최종 등각 타일의 차이이며 추가 영역도 포함한다.
   적용 전에는 문서와 Undo 기록을 변경하지 않는다.
5. 축소가 있으면 확인 체크 후 **Apply resize**를 누른다. Cancel은 변경하지 않는다.
   이후 Undo 한 번으로 전체 변경을 취소할 수 있다. 디스크 저장은 기존 Save As다.

## 지원 계약

- `DIM `, `MTXM`, 있으면 `TILE`·`ISOM`·`MASK`, `UNIT`·`THG2`·`DD2 `·`MRGN`을 한 번에 교체한다.
  누락된 선택 섹션은 합성하지 않고 같은 섹션의 중복이나 잘린 격자/레코드는 거부한다.
- raw MTXM/TILE 및 MASK 겹침 영역은 각각 원래 바이트를 복사한다. 새 raw MTXM/TILE
  셀은 선택한 MTXM raw 값으로 채우고, 새 MASK 셀은 모든 플레이어 숨김 `0xff`다.
- 유닛/스프라이트/두다드 좌표만 타일 이동량 × 32픽셀만큼 이동한다. 레코드 순서,
  class ID·연결 ID·예약 바이트는 유지한다. 객체가 새 경계를 벗어나면 적용을
  막는다. 객체를 자동 삭제하거나 관계를 추측해 수정하지 않는다.
- 로케이션은 ID·이름·고도 플래그를 유지하고 각 좌표를 새 경계로 제한한다.
  역방향 좌표는 정렬하지 않는다. 완전히 잘리는 영역은 경계의 면적 0 영역이 된다.
  빈 레코드는 그대로 두고, ID 64가 원래 맵 전체 영역일 때만 새 전체 영역으로 갱신한다.
- 알 수 없는 섹션, TRIG/MBRF, 원시 문자열·예약 값과 미저장 사운드는 유지한다.
  사용자 코드·EUD 규칙에 직접 적은 픽셀 좌표는 변환하지 않으므로 별도 검토해야 한다.
- 크기 변경 후 타일 선택/카메라 상태를 초기화한다. 변경 사이에 문서 교체·편집,
  저장/빌드 또는 브러시 작업이 발생하면 오래된 미리보기 적용을 거부한다.

## 계층과 안전

`MapResizeEditor`는 순수 도메인 변환과 불변 미리보기를 만든다.
`MapResizeController`는 캡처한 세션 identity, 진행 중 작업과 편집 제한을 확인하고
새 metadata/terrain/object/reference 진단을 검증한 뒤 한 번에 세션을 채택한다.
공통 history에 전후 세션을 기록하며 디스크 I/O는 하지 않는다.
UI는 컨트롤러를 통해서만 적용한다. 이후 Save As는 기존 임시 출력·재검증·승격을 따른다.

## ISOM·두다드 확대 계약

- `MapResizeTerrainEditor`는 로컬 CV5 기반의 불변 카탈로그와 recipe만 사용한다.
  원본의 다이아몬드 투영·인접성·타일 쌍·수직 적층을 먼저 검증한다. ISOM/TILE이
  없거나 모호한 raw MTXM 덮어쓰기가 있으면 추측해서 복구하지 않는다.
- 기존 내부 다이아몬드를 이동하고 새 영역을 표본 평지로 시작한다. 맵 끝에서
  잘려 있다가 새로 노출되는 다이아몬드는 기존 형태를 우선하되 경계를 재계산할 수 있다.
  `solveIsomRegion`은 인접 연결과 렌더 가능한 CV5 타일 쌍의 후보를 축소하고
  결정적 탐색으로 해를 찾는다. 최대 100,000회 시도 후 안전하게 거부한다.
  전체 열의 수직 적층/member 경로를 검사하여 TILE/MTXM을 산출한다.
- 남은 기존 TILE member와 ISOM 값/플래그를 우선 보존한다. 변경된 끝 경계에서도
  예약 bit 0/15를 유지한다. 새 영역에는 새 ISOM padding을 포함한다.
  ISOM 이동량은 가로 4타일·세로 2타일 배수여야 한다. 정렬이 맞지 않는 기존
  비표준 크기/anchor 조합은 적용을 거부하며 임의로 anchor를 바꾸지 않는다.
- 두다드는 종류/타일셋·정렬·활성 값·모든 footprint 타일/required group이 맞는
  recipe가 정확히 하나일 때만 이동한다. 활성 0과 비활성 1은 그대로 유지하며
  그 외 값·겹침·모호한 recipe를 거부한다. 투명 셀을 포함한 전체 footprint의
  바닥 TILE이 재계산으로 달라지거나 일부가 잘리면 적용을 거부한다.
- overlay는 MTXM에 복원한다. DD2와 **모든 THG2**를 같은 이동량으로 옮기고
  어느 스프라이트가 어느 두다드 소유인지 좌표로 추측하지 않는다. 혼합/중복 좌표의
  Sprite도 삭제하거나 병합하지 않는다. 바깥으로 나가는 Sprite는 전체 적용을 막는다.
- 기존 ISOM 없는 TILE/DD2 맵도 검증된 footprint로 이동할 수 있다. ISOM을 합성하지 않는다.
  raw 맵에 두다드가 없으면 기존처럼 로컬 게임 자료 없이 resize할 수 있다.
- 미리보기 후 세션·게임 자료 설정이 바뀌면 적용을 거부한다. 창을 닫으면
  진행 중 snapshot/recipe 요청을 취소하고 늦은 결과를 채택하지 않는다.

## 검증과 남은 범위

자동 테스트는 9개 anchor, 비정사각 확장, 중앙 축소, 지형/안개 겹침 바이트,
객체 이동·경계 거부, 로케이션 clipping/ID 보존, 중복·손상·자료 없는 ISOM/DD2 거부,
미리보기 취소, 오래된 세션·진행 중 브러시 거부와 Undo/Redo를 검사한다.
실제 MPQ 테스트는 저장된 입력의 크기를 변경하고 Save As·재열기에서 CHK 전체
일치와 원본 fingerprint 보존을 확인한다.

실제 MPQ 왕복 1개도 통과했다. analyze 무이슈, Windows debug 빌드 및
4초 시작 확인 통과. 변경 Dart 9개 format 통과; 전체 format은 기존 무관한
infrastructure 테스트 4개의 차이로 미통과다. Flutter 3.47.2/Dart 3.13.2에서
검증했으며 기준 3.44.8/3.12 재검증은 별도다. 기존 CascLib CMake 경고는 남아 있다.

활성/비활성 두다드·원본 불변성·부분 footprint 잘림 거부, 로드 취소/설정 변경·

맵 모서리와 중심의 경계가 있는 지형을 생성하여 9개 anchor의 확장·축소·혼합 변경,
내부 다이아몬드 보존과 재변환 멱등성을 통과했다. 모든 타일셋의 실제 VF4 경사로도
