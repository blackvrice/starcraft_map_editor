# 남은 개발 작업과 검증

2026-10-03, 기본 편집 도구·자동 저장/복구·한영 번역 구현 기준. [개발 계획](DEVELOPMENT_PLAN.md)의 미완료 항목을
중복 없이 묶은 현황이다. 체크박스의 원본은 개발 계획이며 이 문서는 작업 선택을
돕는 요약이다. 기능 구현, 실제 게임 확인, 배포 인수를 서로 구분한다.

## 현재 완료 범위

맵 Open/Save As, New Map·신규 MPQ 저장, raw·ISOM·두다드 맵 resize, 배치/기본 설정,
일반 트리거·브리핑·문자열·사운드 편집, 문서 Undo/Redo가 구현되어 있다.
[기본 편집 도구](BASIC_EDITING_TOOLS.md)의 안개·시작 위치·상태/valid flags·관계·고도/검색,
Sprite/Doodad 상태·문서 내 clipboard·미니맵·겹침 선택·단축키도 구현했다.
[선택·탐색](SELECTION_NAVIGATION.md)의 이름/ID·소유자 검색·관련 선택과 좌표 이동·화면 맞춤을 구현했다.
[EUD 보완](EUD_COMPLETION.md)의 로컬 DAT 58개 기본값·원본/예정 참조 그래프·TRIG/현재 소스 정적 충돌을 구현했다.
EUD 관리형 도구 동봉, 61개 후보 필드, 실행 규칙과 명시적 테스트 빌드도 구현했다.
[한영 번역](LOCALIZATION.md)의 설정·리소스·브리핑 세부·epScript·내장 진단 번역과 Windows 글꼴/줄바꿈 검증도 완료했다.

등각 지형은 평지 채우기·[기존 ISOM 전환/수직 적층 재계산](ISOM_TRANSITIONS.md)· [경계/높이·경사로 브러시](ISOM_BRUSHES.md)까지 구현했다.

- TILE/ISOM 읽기 전용 검사와 MTXM 차이 표시.
- 주입형 카탈로그를 사용하는 비적층 변환 코어, 미리보기·적용·Undo/Redo.
- 실제 로컬 CV5 연결 스냅샷·자산 해시와 Dart 수신/검증·취소·출력 제한.

- 로컬 평지 형태 연결표·변환 카탈로그와 자료/알고리즘 버전 결합.
- File → 등각 지형 채우기: 변경 수 미리보기, ISOM/TILE/MTXM 동시 적용과 Undo/Redo.

8개 타일셋 평지 86종 생성/렌더와 자체 제작 MPQ Save As/재열기를 검증했다.
실제 게임·외부 에디터 확인을 완료했다고 표시하지 않는다.

## 남은 코드 작업

| 분야 | 남은 구현 | 계획 연결 |
| --- | --- | --- |
| EUD 후속 확대 | [기본값·공유 그래프·정적 충돌](EUD_COMPLETION.md)은 구현. 동적 코드·IScript/HD 분석은 확장 범위이며 게임 인수와 분리 | M6.3.1~2 |
| 사용성 | 한영 번역·진단 ID화·Windows 한글 줄바꿈은 완료. 접근성·고대비, Ctrl+K·떠 있는 도구 막대·유닛 중심 EUD 목업 요소 검토는 남음 | UX v2, M8 |
| 안정화·배포 | [자동 저장·미저장 복구](AUTOSAVE_RECOVERY.md)는 구현(2026-10-03). 로그 개인정보 제거, 대표 대용량 맵 추가 프로파일링, 패키징·업데이트/복구·버전/마이그레이션 정책은 남음 | M8, X5 |
| 추가 언어 확장 | 정식 Python entry·진단·프로젝트 마이그레이션, 제한 Lua 문법·변환기·원본 위치 진단 | X3/X4 |

기본 epScript 빌드는 이미 구현되어 있다. Python이 euddraft 내부에서 쓰인다는
사실은 앱의 정식 Python entry 지원과 다르다. Lua는 아직 미지원이다.
기존 타일/객체 성능 계측과 사용자 확인은 보존한다. M8의 프로파일링은 릴리스
대표 맵으로 범위를 넓히는 작업이며 이전 확인을 취소하는 뜻이 아니다.

## 구현과 별도로 남은 검증

| 대상 | 남은 확인 |
| --- | --- |
| 기본 편집 도구·Doodad 복합 편집 | 상태/관계·고도·안개·복합 enabled/clipboard의 실제 게임·외부 에디터 왕복, 미지원 사례 확대 |
| 기본 설정 | 무기·업그레이드·클로킹, 생산·연구·플레이어·세력 등 남은 게임 사례 |
| EUD 후보 필드 | 전체 필드 조합·공유 영향·classic/HD·생성/변신/회복·멀티플레이. 사용자 확인된 실드·공격 간격만 확인 범위로 유지 |
| 트리거·브리핑·실행 규칙 | 실제 실행 순서·텍스트/초상화/소리/시간, 객체 생명주기·성능·두 클라이언트 동기화 |
| 기본 제작 흐름 | New Map → 설정 → 지형/객체/안개 → 트리거/브리핑/리소스 → Save As → 재열기 → SC:R/외부 에디터 |
| 배포 | 깨끗한 Windows 설치/실행/제거, 읽기 전용 ACL·차단망, 오프라인 동봉·업데이트/복구, 최종 패키지 전체 라이선스 고지 검사 |

일부 라이선스 고지·도구 무결성·개발 PC 빌드 검증은 이미 구현/검증되었다.
이 목록의 배포 인수는 그것을 새로 만드는 작업이 아니라 실제 배포물 전체를
독립 환경에서 확인하는 게이트를 포함한다.

## 다음 작업 선택

등각 브러시와 [ISOM·두다드 맵 크기 변경](MAP_RESIZE.md)의 코드 작업을 완료했다.
다음 코드 분야는 사용성, 크래시 로그 등 후속 안정화, 추가 언어 확장이다. 자동 저장·복구와 남은 한영 번역은 2026-10-03 구현했다. 우선순위는 개발 계획과 사용자 지시를 따른다.
개발 계획의 맨 앞 미완료인 Doodad 게임/외부 에디터 검증은 관찰 대기로 유지한다.
사용자의 우선순위 변경이나 새 검증 결과가 없다면 완료 표시하지 않는다.

평지 채우기·재계산·새 경계/높이·선택 영역 브러시·VF4 경사로와 시각 미리보기는 구현했다.
실제 ISOM 지형의 게임 통행·외부 에디터 편집/재저장 확인은 별도다.

최근 기능 검증은 [지형 검증 기록](ISOMETRIC_TERRAIN.md), 이번 문서 점검과
실행 결과는 [문서 정합성 점검](DOCUMENTATION_REVIEW.md)을 따른다.
