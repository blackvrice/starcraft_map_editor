# 업그레이드 설정

File → Upgrade Settings…에서 업그레이드의 비용·연구 시간·레벨당 증가량과
맵 기본 시작/최대 레벨, 플레이어 1~8의 시작/최대 레벨·상속을 편집한다.
유닛의 무기 피해량 증가나 EUD 확장 설정과 별개다.

## 지원과 편집 규칙

- 알려진 단일 VER가 59/63이면 UPGS/UPGR(46개), 205/206이면 UPGx/PUPx(61개)를 편집한다.
  업그레이드는 검증되지 않은 이름 대신 숫자 ID로 표시한다.
- 비용과 레벨 그룹을 독립 검증한다. 누락·중복·크기 오류가 있는 그룹만 비활성화하고,
  정상인 다른 그룹은 계속 편집할 수 있다. 반대 버전 섹션은 동기화하지 않는다.
- 비용·시간·증가량은 u16(0~65535), 시작/최대 레벨은 u8(0~255)의 정수다.
  표시된 범위는 저장 필드 범위이며, 각 업그레이드가 게임에서 지원하는 레벨
  상한을 보장하지 않는다. 시간은 1/60초 단위로 입력한다.
- 비용의 게임 기본값 사용은 플래그만 바꾸며 저장된 사용자 수치를 지우지 않는다.
  게임의 기본 비용을 로컬 DAT에서 읽어 표시하는 기능은 아직 연결하지 않았다.
- 맵 기본 레벨은 이를 상속하는 플레이어에게 적용된다. 플레이어 9~12는 읽기
  전용으로 표시한다. 상속을 켜도 저장된 개별 레벨은 유지한다.
- 새 기본값/상속 플래그는 0/1만 받는다. 기존 비표준 값은 숫자로 표시하고
  수정하지 않으면 보존한다. 비표준 상속의 최종 레벨은 unknown으로 표시한다.
- 직접 수정한 시작/최대 쌍과 새로 선택한 상속 대상은 시작 ≤ 최대여야 한다.
  무관한 기존 비정상 값은 자동 수정하거나 변경 전체의 거부 이유로 삼지 않는다.
  상속 대상의 값이 유효하면 비활성 개별 값이 비정상이어도 보존할 수 있다.

선택을 바꿔도 초안을 유지한다. Apply는 모든 초안을 검증하여 한 명령으로 적용하고
Cancel은 미적용 초안만 버린다. 공유 Undo/Redo를 사용하며 오류 후에도 초안을 유지한다.
오래된 문서 스냅샷에 대한 적용은 거부한다. Save As는 기존 저장 파이프라인을 사용한다.

## 저장 구조

[SEN CHK 명세](https://wiki.staredit.net/wiki/Scenario.chk)의 UPGS/UPGx와 UPGR/PUPx를 따른다.
UPGx 예약 바이트는 **끝이 아니라 오프셋 61**, useDefault 배열 바로 뒤다.

| 배열 | UPGS 시작 오프셋 | UPGx 시작 오프셋 |
| --- | --- | --- |
| 기본값 플래그 u8[N] | 0 | 0 |
| 예약 u8 | 없음 | 61 |
| 기본 미네랄 u16[N] | 46 | 62 |
| 미네랄 증가량 u16[N] | 138 | 184 |
| 기본 가스 u16[N] | 230 | 306 |
| 가스 증가량 u16[N] | 322 | 428 |
| 기본 연구 시간 u16[N] | 414 | 550 |
| 연구 시간 증가량 u16[N] | 506 | 672 |
| 전체 크기 | 598 | 794 |

u16은 little endian이며 N은 46/61이다. UPGR/PUPx는 모든 배열이 u8이다:
플레이어 최대[12N], 플레이어 시작[12N], 맵 최대[N], 맵 시작[N],
플레이어 상속[12N] 순서이며 오프셋은 0, 12N, 24N, 25N, 26N이다.
전체 크기는 38N(1748/2318)이다.

변경한 필드만 패치한다. UPGx 예약 바이트, 미편집 수치·플래그·예약 플레이어,
반대 버전 섹션, 알 수 없는 섹션과 문자열 원시 바이트를 보존한다.

## 검증과 제한

합성 원본/확장 golden bytes로 6개 비용 배열의 마지막 항목과 마지막 편집 가능
플레이어의 레벨/상속 오프셋을 확인한다. 범위·시작/최대 관계·독립 그룹 오류·
기본값 보존·원자적 거부를 테스트한다. 위젯 테스트는 선택 간 초안, 오류 후 수정,
취소·기본값·상속·Undo/Redo·예약 플레이어 읽기 전용을 확인한다.
가짜 아카이브 통합 테스트는 Save As/재열기 후 UPGx/PUPx 전체 바이트와
오래된 문서에 대한 적용 거부를 확인한다.

실제 SC:R 게임 적용과 업그레이드별 유효 레벨 상한은 미검증이다.
검색·선택 범위 적용은 후속 설정 UX 작업에 남겨 둔다.
