# Map Settings 통합 탭

맵을 연 뒤 맵·Catalog 옆의 Map Settings 작업 탭에서 Map, Players, Forces, Units, Availability, Upgrades,
Tech의 7개 설정 영역을 편집한다. File → Map Settings…도 같은 작업 탭을 선택한다. 기존 개별 File 메뉴도 사용할 수 있다.
Map Settings는 맵 전체 설정이며 캔버스 Inspector는 배치된 객체의 개별 속성이다.

## 유닛 미리보기와 연관 선택 (2026-09-17)

설정 탭에 구분 아이콘을 추가했다. Units에는 로컬 StarCraft 그래픽의 유닛 미리보기,
기본 이름·ID, 지상/공중 무기와 서브유닛 연결 카드를 표시한다. 설치/이미지가 없으면
대체 아이콘과 안내를 표시한다. 이는 게임의 명령 버튼 아이콘 전체를 추출하는 기능은 아니다.

유닛 선택 시 검증된 DAT 연결의 지상 무기 → 공중 무기 → 서브유닛 순서로 공유 무기를
자동 선택한다. 서브유닛 순환 참조는 방문한 ID에서 중단한다. 카드의 무기 버튼으로
지상/공중 무기를 직접 전환하고 서브유닛 버튼으로 해당 유닛을 선택할 수 있다.
자동 선택은 편집 대상만 바꾸며 입력 초안·수치·맵 바이트·Undo 기록을 변경하지 않는다.
무기 없음/조회 실패는 기존 수동 무기 선택을 유지하고 명시적으로 안내한다.
선택 가능한 무기 범위 밖 ID는 기본 설정에 자동 선택하지 않는다.

설치·맵 변경 및 빠른 유닛 전환 뒤 늦은 응답은 폐기한다. 이미지 조회는 배치 Catalog의
선택·페이지를 변경하지 않는다. 원시 자산이나 추출 이미지를 저장소/배포물에 추가하지 않는다.
업그레이드·테크 자동 선택은 확정된 연결 데이터가 없어 이번 범위에 포함하지 않는다.

검증: 전체 642개 통과·16개 선택 환경 skip, 정적 분석 및 Windows debug 빌드·5초
시작 스모크 통과. 실제 로컬 설치의 유닛 미리보기/무기 참조를 포함한 집중 26개도
통과했다. 화면 상호작용은 위젯 테스트로 검증했고 실제 Windows 화면 수동 조작과
게임 실행은 수행하지 않았다. SDK는 Flutter 3.47.2/Dart 3.13.2로 기준과 다르며,
전체 비쓰기 포맷 게이트는 기존 infrastructure 테스트 4개의 형식 차이가 남는다.

## 초안과 적용

- 처음 방문한 탭만 로드한다. 탭 전환은 초안·선택·검색을 유지하고 문서를 변경하지 않는다.
- Apply는 **현재 탭**의 전체 초안을 검증하여 한 Undo/Redo 명령으로 적용한다.
  모든 탭을 동시에 적용하는 명령은 아니다. Save As가 실제 파일을 쓴다.
- Discard tab draft는 현재 탭의 미적용 입력을 버리고 최신 문서를 읽는다.
- 다른 탭의 Apply 또는 공유 Undo/Redo로 문서가 바뀌면, 초안이 없는 탭은 갱신한다.
  초안이 있는 탭은 값을 유지하되 Apply를 비활성화하고 충돌 안내를 표시한다.
  Reload and discard this draft를 선택하면 현재 탭만 최신 문서로 다시 읽는다.
  오래된 초안을 최신 문서에 추측하여 합치지 않는다.
- Undo/Redo는 모든 편집기의 공통 기록이다. 현재 탭의 해당 버튼을 누르면 그 탭의
  미적용 입력을 폐기하고 결과를 다시 읽는다. 다른 탭의 미적용 입력은 보존한다.
- Close 또는 뒤로 가기로 닫을 때 미적용 초안이 있으면 Keep editing /
  Discard and close를 선택한다. 이미 적용한 변경을 폐기하는 동작은 아니다.
  배경 클릭으로 통합 창을 실수로 닫지 않도록 한다.

## Players/Forces와 플레이어 범위

[공통 검색과 범위 복사](SETTINGS_EDITING_UX.md)를 사용한다.

| 선택 | 표시·입력 번호 | 복사 내용 |
| --- | --- | --- |
| Players | Player 1~8 (9~12는 읽기 전용) | 현재 플레이어에서 수정한 슬롯·종족·색상 |
| Forces의 플레이어 배정 | Player 1~8 | 현재 플레이어의 수정한 세력 배정 |
| Forces의 세력 | Force 1~4 | 현재 세력의 수정한 이름·옵션 |
| Availability | Player 1~8 | 현재 유닛의 수정한 플레이어 허용·상속 |
| Upgrades | Player 1~8 | 현재 업그레이드의 수정한 플레이어 시작/최대·상속 |
| Tech | Player 1~8 | 현재 테크의 수정한 플레이어 허용·연구 완료·상속 |

플레이어·세력 검색의 #1은 화면의 1번을 뜻한다. 범위 2-3은 2번과 3번이며
내부 저장 인덱스로 변환한다. 숫자 0이나 예약 플레이어를 대상으로 한 범위는 거부한다.
유닛·무기·업그레이드·테크 종류 ID는 기존대로 0부터다.

맵 기본값을 선택한 상태에서는 플레이어 범위 복사를 비활성화한다.
플레이어 범위 복사는 맵 비용·맵 기본값·다른 종류 ID의 초안을 포함하지 않는다.
세력 이름·옵션 범위와 플레이어 배정 범위도 분리한다.
범위 복사는 초안만 준비하며 실제 Apply에서 기존 도메인 검증과 문자열 보존을 거친다.

## 검증과 남은 범위

위젯 테스트에서 모든 탭 방문, 탭 간 초안 보존, 깨끗한 탭 갱신,
오래된 초안 적용 차단·재읽기, 공유 Undo/Redo, 다른 탭에 남은 초안의 닫기 보호와
900×700 창 레이아웃을 확인한다. 플레이어·세력 범위 6개 경로의 섹션 바이트·
예약 범위 거부·Undo/Redo도 검증한다. 좁은 창의 기존 문서 탭은 가로 스크롤,
지도 요약 문자열은 줄바꿈으로 넘침을 방지한다.

다음 개발 계획 항목은 설정별 저장 왕복 증거를 정리하고 실제 SC:R 게임 적용을
검증하는 것이다. 실제 게임 연구·생산·설정 동작은 통합 UI 구현만으로 검증됐다고
표시하지 않는다.

## 작업 영역과 유닛 이름 (2026-09-13)

설정 작업 탭은 별도 모달 창을 띄우지 않는다. 설정이 활성화되면 좌우 객체 패널을
숨겨 편집 공간을 확보한다. 맵/Catalog/EUD 작업 탭으로 이동했다 돌아와도 설정
초안·검색·선택을 유지한다. Apply/Undo/Redo 후에도 설정 작업 탭에 머문다.
Close는 기존 초안 폐기 확인을 거쳐 설정 상태를 초기화하고 맵 작업 탭으로 돌아간다.
다른 맵을 열었을 때 남아 있는 초안은 기존 스냅샷 충돌 규칙에 따라 적용을 차단한다.

Units 선택 목록은 사용자 입력 초안 → 맵의 사용자 지정 이름 → 기본 유닛명 순으로
표시하고 항상 숫자 ID를 함께 표시한다. 기본 유닛명은 BWAPI 공식 UnitType ID 목록의
0~227 매핑을 대조한 영문 이름이다. 기본명 표시는 CHK에 이름을 새로 저장하지 않는다.
사용자 이름과 기본 이름 표시를 검색할 수 있으며 #ID 정확 검색도 유지한다.

매핑 출처: https://github.com/bwapi/bwapi/blob/main/bwapi/BWAPILIB/Source/UnitType.cpp
참고 프로젝트 라이선스: [BWAPI LGPL-3.0](licenses/BWAPI.txt).
게임 설치의 언어별 번역 이름을 읽는 기능은 이번 범위에 포함하지 않는다.

기본 이름 표시는 Availability의 유닛, Units의 무기, Upgrades·Tech의 종류 목록과
무기 영향 목록의 유닛에도 적용한다. Availability도 저장된 유닛 사용자 이름을
우선한다. BWAPI에서 이름이 비어 있는 슬롯은 종류와 숫자 ID로 남긴다.
무기 130개·업그레이드 61개·테크 44개의 인덱스를 유지하여 빈 항목 때문에 ID가
당겨지지 않도록 한다. 해당 목록에서도 기본 이름과 #ID 검색을 지원한다.
매핑 출처는 같은 공식 저장소의 WeaponType.cpp, UpgradeType.cpp, TechType.cpp다.
