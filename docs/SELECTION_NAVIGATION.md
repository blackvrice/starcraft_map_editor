# 선택·탐색

2026-10-01 구현. Edit → 선택·탐색에서 현재 문서의 유닛·Sprite·Doodad·로케이션을
이름/종류 ID/좌표로 찾는다. 유닛 사용자 이름이 없으면 기본 이름을 표시한다.
구조가 불명확한 ID에는 이름을 추측하지 않는다. `#ID`는 정확한 종류 ID 검색이다.
레이어·소유자·선택 가능한 객체 필터를 제공하며 검색 자체는 현재 선택을 유지한다.
체크박스 또는 검색 결과 선택으로 명시적으로 선택한다. 숨김·잠금 객체는 조회할 수
있지만 선택할 수 없다. 이전 문서의 검색 결과는 적용을 거부한다.

전체 선택/반전은 활성 객체 레이어에 적용한다. Terrain이 활성 상태이면 모든 선택 가능한
객체 레이어에 적용한다. 같은 종류/소유자는 현재 첫 선택을 기준으로 한다.
선택 교체는 모든 참조의 존재·선택 가능 여부를 확인한 뒤 한 번에 수행한다.
검색/선택/화면 이동은 맵 바이트·dirty·Undo/Redo 기록을 변경하지 않는다.

| 맵 작업 단축키 | 동작 |
| --- | --- |
| Ctrl+F | 객체 검색 |
| Ctrl+G | 좌표 이동 입력 |
| Ctrl+A / Ctrl+I | 전체 선택 / 선택 반전 |
| Ctrl+Shift+T | 같은 종류 선택 |
| Ctrl+J / Ctrl+Shift+J | 선택 중심 이동 / 선택 범위에 화면 맞춤 |
| Escape | 캔버스 선택 해제 또는 진행 중 편집 취소 |

텍스트 입력의 Ctrl+A는 텍스트 전체 선택으로 동작한다. 픽셀/타일 좌표 이동은 맵 경계를
검사하고 타일 좌표는 타일 중심으로 이동한다. 지형 선택과 객체 범위 맞춤, 전체 맵 맞춤을
제공한다. 화면 이동 시 진행 중 배치·브러시·선택 드래그를 취소한다.
선택 모드에서 우클릭하면 겹친 객체 목록에서 직접 고른다. 메뉴 취소는 선택을 유지하며
Alt 클릭의 기존 겹침 순환도 유지한다.

## 구조와 검증

`SelectionNavigationController`는 typed CHK와 레이어 상태만 읽고 Presentation에
문서 identity가 포함된 검색 결과·화면 범위를 반환한다. 카메라는 Canvas가 관리한다.
UI는 파일 시스템·파서·네이티브 helper를 호출하지 않는다.

집중 검색/필터/원자적 선택/스테일 응답/Redo 보존, 한영 대화상자, 텍스트 단축키,
겹침 메뉴와 256×256 화면 이동 테스트를 추가했다. 전체 Flutter 테스트 871개 통과,
37개 환경 선택 테스트 skip, analyze 무이슈. Windows debug 빌드·시작 검증도 수행한다.
SDK Flutter 3.47.5/Dart 3.13.4로 저장소 기준 3.44.8/3.12와 다르다.
변경 Dart 파일의 format은 통과하며 전체 비쓰기 format 게이트는 기존 무관한
infrastructure 테스트 3개의 차이로 미통과다. 실제 게임/외부 에디터 인수와 릴리스
성능 인증은 이번 읽기 전용 탐색 검증에 포함하지 않는다.
