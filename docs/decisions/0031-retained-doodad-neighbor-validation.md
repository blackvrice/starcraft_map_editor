# ADR-0031: 동일 종류의 미선택 두다드 이웃 검증

- Status: Superseded by [ADR-0032](0032-other-type-doodad-neighbors.md)
- Date: 2026-10-20
- Supersedes: [ADR-0030](0030-reviewed-location-mixed-deletion.md)

## Context

선택한 두다드끼리는 검증한 전체 footprint로 겹침을 판단하지만, 미선택 이웃은
최대 16x16 영역으로 보수적으로 차단했다. 따라서 실제로 겹치지 않는 동일 종류의
인접 두다드도 함께 선택해야 삭제할 수 있었다. 이웃을 삭제 요청에 추가하거나
좌표만으로 크기/overlay 귀속을 추정해서는 안 된다.

## Decision

기존 단일/다중·Unit/Sprite/Location 삭제 계약은 유지한다. 삭제 창은 기존
카탈로그 한 번 순회에 `requireCompleteTypes: true`를 전달한다. 요청한 종류의
후보 중 하나라도 recipe가 없으면 그 종류 전체를 빈 결과로 반환한다. 모든 페이지의
출처/순서/문서 identity 검증 뒤에만 결과를 반환한다. 기본 조회/상태 편집 정책은
변경하지 않는다. 유효한 후보가 여러 개이면 미선택 이웃의 크기를 자동 선택하지 않는다.

UI는 **카탈로그 후보가 정확히 하나인 선택 종류**만 `retainedNeighborRecipes`로
application/domain에 전달한다. 이 인자는 완전한 로컬 카탈로그 조회 결과를 전달하는
내부 계약이지 임의/외부 recipe의 진위를 증명하는 API가 아니다. domain은 최대
32종이며 key/type이 일치하고 삭제 선택에 포함된 종류인지 검사한다.

기존 최대 반경에 들어온 미선택 이웃은 알려진 DD2 상태 0/1, 타일셋, 정렬, 맵
경계와 recipe의 모든 쓰기 MTXM 셀을 검사한다. 성공한 원본 DD2 인덱스/recipe를
계획 내부에만 보관하고 모든 삭제 대상과 **전체 직사각형**이 겹치지 않아야 허용한다.
투명 셀도 겹침 배제 영역에 포함한다. 같은 이웃은 한 계획에서 한 번만 지형 검증하며
최대 256개를 허용한다. 멀리 떨어진 원시 레코드는 재해석하지 않는다.

이웃은 삭제 요청/overlay 확인 집합에 추가하지 않는다. 해당 DD2와 지형, 삭제/선택
인덱스에 없는 THG2는 원시 bytes 그대로 보존한다. 이웃 아래 TILE이나 overlay는
변경하지 않으므로 복원/귀속 검사를 확장하지 않는다. 명시적으로 따로 선택한 Sprite를
제거하는 기존 혼합 계약은 유지한다. `preservedNeighborRecordIndices`는 불변 집합이다.
DD2와 MTXM의 불완전한 레코드/격자는 삭제 시 trailing bytes를 잃지 않도록 거부한다.

## Alternatives

- 가장 먼저 맞는 recipe 사용: 다른 후보의 크기를 배제할 근거가 없어 거부한다.
- 손상 후보를 무시하고 남은 하나 사용: 완전한 후보 집합이 아니므로 거부한다.
- 다른 종류까지 추가 조회: 카탈로그 순회/지원 범위 확대를 별도 후속 작업으로 둔다.
- 미선택 이웃도 삭제: 사용자 선택과 데이터 보존 계약을 위반하므로 하지 않는다.

## Consequences and Validation

단일/다중 확인 창은 기존 조회 한 번을 재사용하며 추가 atlas/thumbnail/I/O나
장기 캐시가 없다. 서로 겹친 미선택 이웃들 자체의 무결성을 증명하는 기능은 아니다.
삭제할 전체 영역과의 비겹침 및 영향 bytes 보존만 확인한다. 다른 종류/복수 후보/
손상 이웃·실제 겹침·TILE 부족은 계속 거부한다. 이웃 없는 기존 복수 recipe 선택은
계속 지원한다. 게임/외부 에디터 인수나 실제 성능 개선 수치를 주장하지 않는다.
요구사항 체크리스트·자동 검증·한계는 [실행 기록](../DOODAD_DELETION.md)에 남긴다.
