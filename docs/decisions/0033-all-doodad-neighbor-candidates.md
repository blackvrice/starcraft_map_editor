# ADR-0033: 복수 이웃 후보의 전체 footprint 검증

- Status: Accepted
- Date: 2026-10-20
- Supersedes: [ADR-0032](0032-other-type-doodad-neighbors.md)

## Context

미선택 이웃은 완전한 단일 후보만 허용했다. 복수 후보 중 하나를 고르면 실제
다른 크기/투명 셀의 영역을 놓칠 수 있다. 이웃을 변경하지 않으므로 실제 정의를
하나로 결정할 필요는 없지만 모든 가능한 영역이 삭제 대상 밖이라는 근거가 필요하다.

## Decision

기존 단일/다중/Unit/Sprite/Location 삭제와 조회 종류 32종·이웃 256개 상한을 유지한다.
UI는 `requireCompleteTypes: true`로 얻은 전체 결과를 `retainedNeighborCandidates`로
전달한다. 손상/누락 후보를 제거하여 완전한 집합인 것처럼 전달하지 않는다. 누락된
종류는 기존 complete-type 정책에 의해 빈 결과이며 삭제를 추측 허용하지 않는다.

domain은 기존 단일 recipe 인자를 하위 호환으로 유지한다. 두 인자 사이 중복 종류,
key/type 불일치·총 32종 초과를 거부한다. 전체 후보는 합계 256개 이하로 snapshot하며
모든 iterable을 합해 최대 257개까지만 읽는다. 후보 목록/종류 map은 불변이다.

실제 가까운 이웃마다 DD2 상태 0/1과 모든 후보의 타일셋·정렬·전체 맵 경계를
검사한다. 어떤 후보라도 geometry를 검증할 수 없으면 전체 거부한다. 적어도 한
후보의 모든 쓰기 MTXM 셀이 현재 지형과 일치해야 한다. 하지만 불일치 후보를
영역 검사에서 제외하지 않는다. 그 후보의 지형이 수정된 객체일 가능성을 배제할
수 없기 때문이다. **모든 후보의 전체 사각형**을 모든 삭제 대상과 대조한다.
투명 셀/지형 불일치 대안 중 하나라도 겹치면 전체 거부한다.

이는 실제 정의 식별이나 이웃의 완전한 무결성을 보장하는 기능이 아니다. 가능한
전체 영역 밖만 변경한다는 검증이며 이웃 DD2/지형·미선택 THG2/TILE은 그대로 둔다.
별도 선택 Sprite 삭제 및 명시 overlay 귀속 정책은 유지한다. 준비는 읽기 전용,
Apply는 기존 identity/잠금 검증 및 한 Undo/Redo를 사용한다.

## Work Bounds

- 전체 입력 후보 최대 256개, 종류 최대 32개, 검증 이웃 최대 256개.
- footprint 셀 검사 최대 262,144회/계획. 투명 셀도 작업 예산에 포함한다.
  불일치 발견 시 해당 후보의 남은 셀만 생략하며 영역 자체는 검사한다.
- 동일 이웃의 후보 검증은 한 계획 내부에서 한 번만 수행하고 모든 대상에 재사용한다.
- 선택 최대 32개에 대해 후보 영역 대조의 보수적 상한은 2,097,152회다.
- 추가 catalog/atlas/thumbnail 요청 또는 장기 cache는 없다. 실제 시간/RSS는 미측정이다.

## Alternatives

- 처음 맞는 후보 채택: 다른 후보의 전체 크기를 배제할 수 없어 하지 않는다.
- 지형 불일치 후보 버리기: 수정된 지형을 가진 이웃일 수 있으므로 영역은 보존 검증한다.
- geometry가 불명확한 후보 제외: 손상 입력을 정상으로 추정하게 되어 전체 거부한다.
- UI에서 임의 정의를 강제로 선택: 실제 불명확한 footprint의 안전 근거를 대체하지 못한다.

## Validation and Remaining Scope

단일/다중·overlay 3종 원시 보존, 투명/지형 불일치 겹침, 후보/셀 예산의 정확한
경계와 무한 입력, batch cache 재사용, 한영 UI/혼합/취소/Undo/MPQ를 검증한다.
기존 복수 후보 UI 거부 기대는 이 프로필에서 모든 영역이 안전하면 허용하도록 바꾼다.
실제 게임/외부 에디터, 어떤 후보도 지형 불일치, geometry 불명확, 실제 겹침,
복원 정보 부족은 미완료/미지원이다. [실행 기록](../DOODAD_DELETION.md)을 따른다.
