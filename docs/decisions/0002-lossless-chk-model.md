# ADR-0002: Raw-first 무손실 CHK 모델

- Status: Accepted
- Date: 2026-07-26

## Context

`scenario.chk`는 여러 이름의 섹션으로 구성되며, 편집기가 모든 섹션과 버전별 변형을 처음부터 이해할 수 없다. 지원하는 데이터만 새 모델로 직렬화하면 알 수 없는 섹션, 중복, 예약 비트, 문자열 바이트가 사라질 수 있다.

## Decision

원시 섹션 문서를 보존하고, 편집 가능한 typed view를 그 위에 투영한다.

- 섹션의 이름, 순서, 중복, 페이로드를 보존한다.
- 수정되지 않은 섹션은 원시 바이트를 그대로 쓴다.
- 지원 섹션도 알 수 없는 필드를 보존할 방법이 없으면 편집하지 않는다.
- 변경 없는 CHK의 byte-exact round-trip을 핵심 테스트로 둔다.
- 저장 후 출력 아카이브를 다시 열어 검증한다.

## Alternatives

### 모든 섹션을 완전한 객체 모델로 변환

사용하기 쉬우나 구현되지 않은 필드와 버전 변형을 잃을 위험이 크다.

### 외부 편집기/라이브러리에 모든 CHK 처리를 위임

초기 개발은 빠르지만 UI 편집 모델과 오류 위치, 무손실 보장을 통제하기 어렵다.

### 원시 바이트 편집만 제공

무손실이지만 일반 사용자가 지형과 객체를 편집하기 어렵다.

## Consequences

- 새 섹션을 점진적으로 지원할 수 있다.
- 원시 문서와 typed view 동기화 규칙이 필요하다.
- 부분 편집 인코더와 dirty 추적이 복잡해진다.
- 안전하게 지원할 수 없는 필드는 읽기 전용으로 노출된다.

## Validation

- 알 수 없는/중복 섹션 픽스처
- 변경 없는 byte-exact 왕복
- 한 섹션 변경 시 다른 섹션 바이트 비교
- 실제 자체 제작 맵 Open/Save As/재열기
