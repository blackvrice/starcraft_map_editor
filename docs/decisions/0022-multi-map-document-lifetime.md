# ADR-0022: 여러 맵 문서 수명과 경로 점유

- 날짜: 2026-10-16
- 상태: Accepted (에디터/자동 회귀 범위, 실제 앱/게임 인수 별도)
- 범위: FR-005 / EP3b 첫 항목. FR-222 문서 간 복사는 별도.

## 결정

단일 OpenMapController의 snapshot을 교체해서 탭을 흉내내지 않는다. 문서별
컨트롤러 묶음과 stable ID를 만들고 화면도 keyed Stack/Offstage로 유지한다.
공유하는 것은 언어/설치/도구 설정, 최근 경로와 읽기 전용 gateway뿐이다.
Undo, 선택, 카메라, 폼, 리소스, EUD 프로젝트/소스/빌드, 자동 저장은 문서 소유다.

같은 실제 파일(대소문자·경로 별칭·hard link 포함)을 다시 열면 기존 탭을 선택한다.
Save As·EUD 출력·프로젝트 저장은 열린 문서 입력과 다른 출력 예약을 검사하고,
예약은 비동기 작업 종료까지 유지한다. 기존 physical-path 비교 포트를 재사용한다.
원본 덮어쓰기 금지와 임시 출력/재검증/교체 정책을 완화하지 않는다.

새 맵과 복구는 별도 빈 문서에서 준비한다. 취소/실패는 기존 탭을 교체하지 않는다.
복구 파일 이름은 기존 owner ID+sequence를 유지하며 열린 문서 소유 체크포인트는
다른 문서에서 복구/삭제하지 못한다. 복구 결과도 새 탭에서 명시 Save As한다.

문서 탭 전환은 dirty/Undo를 바꾸지 않는다. 진행 중인 브러시 transaction은
완료/취소 전 전환을 거부한다. 다른 문서의 I/O/빌드 결과는 요청 소유 문서에만
반영한다. 작업 중 닫기는 거절하고 종료는 모든 문서를 확인한다.

폼의 미적용 초안은 아직 CHK dirty가 아니므로 깨끗한 맵도 닫기 전에 명시 확인한다.
Save As만으로 epScript/프로젝트/미적용 초안을 저장했다고 간주하지 않는다.
닫기 확인 중 문서 revision이 바뀌면 다시 확인한다. 앱 종료 확인은 전 문서가
동의하기 전 어느 탭도 제거하지 않는다.

## 대안과 비용

컨트롤러 재연결 방식은 기존 비동기 요청/Undo closure/초안이 다른 맵을 가리킬
위험이 있어 제외한다. 보존된 화면/텍스처의 메모리 비용 때문에 탭 수를 제한하고,
닫을 때 소유 구독·요청·텍스처·타이머를 해제한다. 실제 RSS/DPI/외부 에디터·게임
인수는 자동 회귀와 별도로 기록한다.
