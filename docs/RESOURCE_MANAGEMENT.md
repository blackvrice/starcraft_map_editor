# 문자열·사운드 관리

2026-09-27 M6.5 구현. 맵을 연 후 상단 **Resources** 탭에서 **Strings**와
**Sounds**를 선택한다. 편집은 현재 문서에만 반영되며 **Save As**가 새 맵에
기록한다. 일반 트리거와 문서 Undo/Redo 이력을 공유한다.

## 문자열

- 문자열 ID·본문 검색, 원시 바이트 크기, 알려진 사용처 수, 사용처 목록을 표시한다.
- 사용처는 SPRP, FORC, MRGN, SWNM, WAV, UNIS/UNIx 및 일반 TRIG와 MBRF의
  텍스트·사운드 필드다. 비활성 슬롯의 참조도 삭제 보호에 포함한다.
- 공유 ID 편집은 해당 ID의 모든 사용처에 반영된다. `Separate`는 새 ID를 추가하고
  선택한 한 필드만 변경한다. 16비트 필드에는 16비트 범위의 ID만 쓴다.
- `Clear unreferenced string`은 참조가 없는 문자열 내용을 비운다. ID를 제거하거나
  다른 ID를 당기지 않는다. 기존 데이터 뒤에 새 바이트를 추가하여 해당 오프셋만
  변경하므로 파일 크기를 줄이는 문자열 압축 기능은 아니다.
- 기존 문자열을 일괄 재인코딩하지 않는다. 표시·입력은 UTF-8이며 디코딩 실패 시
  오류를 표시하고 명시적인 대체 입력만 허용한다. 변경하지 않은 원시 바이트와
  기존 STR/STRx 형식은 보존한다. NUL 입력은 금지한다.
- 테이블 크기·오프셋 한계와 구조 진단을 표시한다. 잘못된 단일 테이블은 읽기 전용
  조회하고, 누락되거나 여러 문자열 테이블이 존재하면 임의로 선택하지 않는다.
- 알 수 없는 섹션, 중복 섹션, 원시/EUD 트리거 슬롯, 손상된 참조 레이아웃이 있으면
  참조 추적이 불완전하다고 표시하고 미사용 문자열/사운드 삭제를 차단한다.
- 사운드 경로를 공유 문자열 편집으로 바꾸지 못하게 한다. 텍스트 사용처와 공유된
  경우 텍스트 참조만 분리할 수 있다. 사운드 이름 변경/교체는 자동 수행하지 않는다.

## 사운드

- 실제 MPQ의 `.wav` 항목, WAV 등록 및 TRIG/MBRF 사운드 참조, 아직 저장하지 않은
  가져오기 항목을 함께 표시한다. 대소문자가 다른 경로는 같은 이름으로 취급한다.
- `Import PCM WAV`: 8–48 kHz, 8/16비트, mono/stereo 비압축 PCM RIFF/WAVE를
  검증한다. RIFF 길이·청크 경계·패딩·샘플 정렬을 검사한다. 파일당 16 MiB,
  미저장 변경 64개/64 MiB로 제한한다.
- 가져온 이름은 `staredit\wav\파일명.wav`이다. ASCII 상대 경로만 지원하며
  절대 경로·상위 이동·빈 경로 요소를 거부한다. 같은 이름의 실제 파일, 미저장
  변경 또는 사운드 참조가 있으면 다른 이름을 요구한다. WAV 등록은 빈 512개 슬롯
  중 하나와 새 문자열 ID를 사용한다.
- `Preview sound` / `Stop preview`: Windows SoundPlayer를 별도 PowerShell
  프로세스로 실행한다. 파일 경로는 환경변수로 전달하며 코드에 삽입하지 않는다.
  다른 탭/맵으로 이동하거나 뷰를 닫으면 미리듣기를 중단한다.
- `Export sound`: PCM 여부와 무관하게 지원 경로·크기·locale의 파일을 원시 바이트로
  추출한다. 출력 확장자는 `.wav`만 허용한다. 기존 압축 WAV는 보존·추출할 수 있으나
  가져오기/미리듣기에서 변환하거나 지원한다고 가정하지 않는다.
- `Delete sound`: 알려진 사용처가 WAV 등록뿐인 경우 등록 슬롯을 0으로 만들고
  MPQ 삭제를 예약한다. 문자열 ID와 데이터는 보존한다. TRIG/MBRF/다른 사용처가
  남으면 삭제하지 않는다. 미저장 가져오기 삭제는 파일 변경 예약을 취소한다.
- MPQ 목록이 불완전하거나 합성 이름이 있으면 가져오기/삭제를 차단한다.
  locale 0의 단일 항목만 읽기/삭제하며 여러 locale 또는 locale 전용 항목은
  추측하지 않는다. 참조만 있고 맵에 없는 경로는 그렇게 표시한다. 게임 설치의
  기본 사운드일 수 있으므로 자동 삭제하거나 전체 Save As를 금지하지 않는다.

## 저장과 경계

Application의 불변 `PendingMapResources`가 추가 바이트/삭제 표식을 보유한다.
이전 스냅샷의 음원 바이트는 공유하지만 외부 입력 목록은 복사하여 Undo 변조를 막는다.
지형 등 다른 편집이 세션을 교체해도 이 변경을 유지한다. UI는 파일·MPQ·프로세스를
직접 호출하지 않고 `MapResourceGateway` 포트를 사용한다.

`replaceScenario` helper 요청의 선택적 `resourceChanges`를 임시 맵 복사본에
적용한다. helper는 기존 항목 덮어쓰기와 애매한 locale 삭제를 거부하며 실패한
임시 출력을 제거한다. 응답의 `resourceUpdates` 개수를 검증하므로 구버전 helper가
변경을 무시하고 성공하는 경우도 최종 저장하지 않는다. `extractSound`는 helper의
작업 디렉터리 안으로만 추출하며 앱이 protocol/helper/StormLib 버전과 크기를 확인한다.

Save As는 CHK 재열기 검증에 더해 각 추가 음원의 바이트와 삭제 음원의 부재를
다시 읽어 확인하고 나서 최종 경로로 승격한다. 원본 지문과 현재 문서가 달라지면
승격하지 않는다. 성공한 저장 세션만 리소스 변경 예약을 비운다.

## 검증과 남은 실제 환경 확인

- 자체 제작 PCM 무음 fixture로 가져오기·내보내기·취소·형식 오류를 검증한다.
- 도메인 테스트: 공유/분리/삭제 보호, STRx, 잘못된 UTF-8·구조·용량,
  TRIG/MBRF 참조, 경로·WAV 경계.
- 위젯/컨트롤러: 문자열 적용, 소리 가져오기/미리듣기/내보내기 포트 연결,
  중복 이름, 대소문자 경로, 불변 스냅샷, Undo/Redo.
- Save As: 소리 바이트 불일치 시 승격 차단 및 성공 시 dirty 해제.
- 실제 helper와 CTest: 소리 추가·추출·삭제·중복 경로 거부, 원본 및 다른 MPQ
  항목 보존. 재배포한 게임 음원은 테스트/배포물에 포함하지 않는다.
- 실제 오디오 장치에서 들리는지와 SC:R에서 Play WAV/Transmission으로 들리는지는
  별도 사용자 실행 확인이다. 자동 테스트 통과를 게임 실행 확인으로 취급하지 않는다.
